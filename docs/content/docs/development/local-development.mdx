# Local Development

The main application lives in `web/`. The browser sends AI requests directly to the user's OpenAI-compatible endpoint.

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000`, then enter your `Base URL`, `API Key`, and model names in Settings. Prompt sources and WebDAV are also accessed directly by the browser.

## Start the documentation site

```bash
cd docs
bun run dev
```

## Build the Windows desktop app

Double-click `build-desktop.cmd` in the repository root, or run it from a terminal; it installs missing dependencies and builds the installer. On networks where GitHub or npm is slow, double-click `build-desktop-mirror.cmd` to use the npmmirror mirrors.

To run the steps manually, install the web dependencies first (see above), then from the repository root:

```bash
cd desktop
npm ci
bun run dist
```

The NSIS installer is written to `desktop/release/`. Desktop builds keep user data in `%LOCALAPPDATA%\infinite-canvas`, so installing a newer version over the old one preserves canvases, assets, generation history and settings. See `desktop/README.md` for the data layout, uninstall behavior and browser-to-desktop migration.

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
